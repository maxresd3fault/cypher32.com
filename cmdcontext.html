CmdContext

A shareware shell extension for Windows XP, Vista, and 7 developed by cypher32.

For Those With a Terminal Illness!

CmdContext, read aloud as Command Context, is a roughly 1,700 line (yes it really takes that much) C++ Windows Explorer shell extension which adds new options to the right click context menu, allowing you to open various consoles in the current directory. It was not until Windows Vista came out that Microsoft quietly added a hidden option to open the Command Prompt in the current directory (requiring the user to hold down shift while right clicking), and much later until they finally added options for quickly opening PowerShell. CmdContext aims to be a simple tool for power users who still use older versions of Windows lacking an adequate implementation of this feature. It comes with numerous customization options and far more functionality compared to Microsoft's own implementation in Windows Vista / 7. And it's free!

Features:

  • Full compatibility with Windows XP, Vista, and 7!
  • A built in configuration tool with a simple GUI to tweak your settings
  • Icons! (the Microsoft version has no icons)
  • Support for four consoles: Command Prompt, PowerShell, NT Virtual DOS Machine, and the Network Shell
  • Optionally uses the user's theme for Command Prompt and PowerShell!

A Note on Theming

This is actually a little known and seldom used feature in Windows. In XP, Vista, or 7, if you open the properties for a console's Start Menu shortcut (Command Prompt or PowerShell), you can customize the colors, window size, and even the font! CmdContext supports loading this data from shortcuts and launching consoles with your custom themes. When enabled, CmdContext will first search for a shortcut to load from in your user's Start Menu folder, if it can't find one it will look in the system level Start Menu, finally if all the shortcuts are missing it will fall back to the default theme. PowerShell for example by default installs its shortcut to the system level Start Menu, so if you want a custom theme for PowerShell you should probably copy its shortcut to your user level Start Menu as to not change the theme for all users! This feature is marked as "experimental" because CmdContext actually generates a new shortcut on the fly in %temp% with the target directory plus your theme settings. It is unclear if this causes a noticeable performance degradation or not (feel free to check the source code to see the madness required to make this work), I tested this on an SSD and not a mechanical drive. Enable or disable it at your pleasure!
